# 数据目录

　　`data/`用于保存外部参考数据、训练数据契约和小型复现样例。完整数值数据不进入Git。

| 子目录 | 用途 |
| --- | --- |
| `reference/` | 小型参考表、解析解或可公开同步的基准数据 |
| `rve_rno_c48_v2_2000/metadata/` | 2000条固定胞元RVE路径的任务、验收、归一化和划分元数据 |
| `rve_rno_c48_v2_2000/sample/` | 一条HDF5响应样例，用于检查字段和数据读取接口 |
| `raw/` | 外部原始数据，默认由`.gitignore`忽略 |
| `generated/` | FEM或神经网络流程生成的数据集，默认由`.gitignore`忽略 |

　　正式数据集包含2000条路径。生产任务的预分配为1400/300/300；正式训练验收清单采用1600/200/200划分。两者用途不同，不应混用。公开仓库仅保留元数据和一条响应样例，完整2000条HDF5响应保存在研发副本中。
